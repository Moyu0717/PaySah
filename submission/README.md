# Submission checklist

This source package includes runnable code, synthetic fixtures, verification scripts, a license and a tool declaration.

Before formal submission, complete the official proposal and tools templates, attach reviewed Replit and RunPod proof, add the public demonstration video URL, and verify access for the organizer's designated collaborator. Public repository visibility alone does not establish collaborator access. Real Telegram and Google Form acceptance and the deployed source version must be checked separately. Do not publish credentials, customer data, private screenshots or raw feedback.
